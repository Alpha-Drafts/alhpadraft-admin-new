1 Executive Summary

The AlphaDrafts Admin Panel (alpha-drafts-admin-app) serves as the primary internal operations back-office for managing users, academic drafting projects, subscription revenue, and system metrics. Over the recent development cycles, the application underwent an essential architectural migration and rigorous defect remediation to guarantee production stability.

Key Milestone Achieved: The legacy Firebase Client & Admin SDK dependencies have been completely removed from client-side state. The application now runs on an enterprise-grade cookie-based JWT authentication model proxied to the Contabo backend, providing full double-submit CSRF protection and single-flight token rotation.

All core functional surfaces are verified operational. The application compiles cleanly with 0 TypeScript compiler errors, 0 ESLint warnings, and achieves instant page transitions via Next.js Pages Router and React 19.

4 Architecture & Security Highlights

The system enforces zero-trust boundaries between client UI and backend services:

  • Zero Host Hardcoding: API_BASE_URL = "" throughout client components. Next.js server handles all routing via next.config.ts rewrites to .
  • HttpOnly Cookie Tokens: access_token and refresh_token cannot be read by JavaScript, eliminating XSS token theft vectors.
  • Double-Submit CSRF Defense: Non-httpOnly csrf_token cookie is mirrored into X-CSRF-Token header for all state-changing requests (POST, PUT, PATCH, DELETE).
  • Single-Flight Refresh Mutex: pendingRefreshPromise de-duplicates concurrent 401s, preventing server refresh stampedes.
