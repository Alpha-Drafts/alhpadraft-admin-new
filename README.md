# AlphaDrafts Admin Web Application

## Domains

| Environment | URL                                    |
| ----------- | -------------------------------------- |
| local       | <http://localhost:3000>                |
| development | <https://admindev.alphadrafts.com>     |
| staging     | <https://adminstaging.alphadrafts.com> |
| production  | <https://admin.alphadrafts.com>        |

## Getting Started

To install dependencies and run the project, run the following commands:

```bash
yarn install

yarn dev
```

To view the project, go to `http://localhost:3000` in your browser.

## Commit Message Format

```bash
<type>[optional scope]: <description>
```

The type must be one of [build, chore, ci, docs, feat, fix, perf, refactor, revert, style, test].
